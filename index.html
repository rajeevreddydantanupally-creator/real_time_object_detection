Real-Time Object Detection

An AI-powered computer vision project that detects people and common objects from a live webcam using a pretrained YOLO model and OpenCV.

View Source Code Explore Project

About the Project

Object detection is a computer vision task that identifies objects in an image or video and locates them using bounding boxes. This project applies a pretrained deep learning model to webcam frames in real time.

Project objective: Build a practical AI system that can recognize supported objects, display their labels, and show confidence scores on a live camera feed.

Key Features

A simple demonstration of modern AI-based computer vision.

📷

Live Camera

Captures video frames from the laptop webcam using OpenCV.

🧠

YOLO Detection

Uses a pretrained deep learning model to recognize supported objects.

🎯

Bounding Boxes

Draws boxes and object labels around detected items.

📊

Confidence Scores

Displays the model's confidence score for each detection.

How It Works

The program processes the camera feed frame by frame.

  1. Open the webcam using OpenCV.
  2. Capture a video frame.
  3. Pass the frame to the pretrained YOLO model.
  4. Identify supported objects and their locations.
  5. Draw bounding boxes, labels, and confidence scores.
  6. Display the annotated frame until the user presses Q.

Technologies Used

Python

Main programming language used to build the application.

Ultralytics YOLO

Loads the pretrained object detection model and runs inference.

OpenCV

Captures webcam video and displays the detection results.

Important: This website documents the project. The Python webcam application runs locally on a computer with Python, the required packages, and a compatible camera. The website itself does not run the Python detection program.
